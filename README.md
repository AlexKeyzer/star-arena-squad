# Звёздная Арена: Отряд (Star Arena: Squad)

Браузерный аркадный экшен: короткие матчи против ИИ, командные режимы, герои и суперприёмы. Репозиторий: **`star-arena-squad`**.

## Запуск локально

Требуется Python 3. Запусти сервер из корня проекта:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Открой `http://localhost:8080/`. Не запускай `index.html` через `file://`: браузеру нужен HTTP для локальных скриптов и JSON-данных.

## Проверки

```bash
node scripts/run_qa_checks.js
```

В последней проверке автоматический набор прошёл **10/10**. Перед публичным релизом отдельно проверь запуск/матч на целевых браузерах и реальном мобильном устройстве.

## GitHub Pages

Проект статический: можно включить GitHub Pages для корня репозитория (ветка `main`, `/`) и открыть опубликованный URL. Внешние CDN не нужны.

## Структура

- `index.html` — точка входа
- `src/` — логика, рендер, интерфейс и управление
- `styles/` — основной стиль и слой полировки
- `data/` — игровые данные
- `assets/` — 2.5D fallback-спрайты
- `vendor/three.min.js` — локальная библиотека Three.js
- `scripts/run_qa_checks.js` — автоматические проверки проекта
- The sibling `materials/` folder in the ZIP contains store text and media.

## Ограничения материалов

Набор медиа содержит предыдущие игровые кадры и один отмеченный иллюстративный промо-кадр. Видео — короткий беззвучный монтаж, а не raw capture. Перед загрузкой в каталог, требующий реальные скриншоты/запись клиента, замени эти материалы финальными захватами текущей версии.
